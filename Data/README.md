# Data

`data.csv` holds the cumulative Rhodamine B release (ppm) from planar, 1D wrinkled and 2D crumpled graphene oxide nanosheet films at 14 time points over 48 h (2880 min).

The measurements are from M. Liu, D. C. C. Fernandes, Z. S. Saleeba and R. H. Hurt, "Controlled Release of Molecular Intercalants from Two-Dimensional Nanosheet Films", ACS Nano 15 (2021) 20105 to 20115, [doi:10.1021/acsnano.1c07888](https://doi.org/10.1021/acsnano.1c07888), with a correction at [doi:10.1021/acsnano.2c02972](https://doi.org/10.1021/acsnano.2c02972). Please cite that article if you use them. The MIT license of this repository covers the code, not these measurements.
